# Simple Interest Calculator

A simple calculator script written in Bash that computes the simple interest based on user input.

## About Simple Interest
Simple interest is calculated using the following formula:
$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
* **P** = Principal amount (initial investment or loan)
* **R** = Annual rate of interest (in percentage)
* **T** = Time period (in years)

## Prerequisites
* A Unix/Linux environment or a Bash-compatible terminal (Git Bash, WSL, etc.).
